Overlay Compare Camera

使い方:
1. このフォルダ全体を HTTPS で公開してください。
2. Android Chrome で開く → メニュー →「アプリをインストール」または「ホーム画面に追加」
3. iPhone Safari で開く → 共有 →「ホーム画面に追加」

重要:
- カメラ機能は通常 HTTPS が必要です。
- index.html をローカルファイルとして直接開くだけでは、カメラやPWAが制限されることがあります。
- GitHub Pages / Cloudflare Pages / Netlify などの無料ホスティングで十分です。
